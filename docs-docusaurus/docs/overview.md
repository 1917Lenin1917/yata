title: Обзор
---

Этот раздел описывает big-bang переход YATA к notion-like структуре:

- `project` остаётся корневой бизнес-сущностью.
- `nodes` хранит иерархию (страницы/таблицы) произвольной глубины.
- `pages` остаётся payload-таблицей для rich-text контента page-узлов.
- ticket-таблица теперь представляется отдельным узлом типа `ticket_table`.
